# Submission checklist

Use this list before submitting the GitHub repository.

## Linux practical
- [ ] Task 1: user created; login shell and identity checks captured.
- [ ] Task 2: all required FHS paths visited and described.
- [ ] Task 3: `ls`, `ls -l`, `ls -a`; `.lab-notes` verified.
- [ ] Task 4: workspace created; `overview.txt` has at least four lines; checklist has at least three items.
- [ ] Task 5: `app.conf` updated and final contents verified.
- [ ] Task 6: both copies, rename, and safe removal verified.
- [ ] Task 7: `find` and both `grep` searches recorded.
- [ ] Task 8: `644` and `600` verified; `id` explained.
- [ ] Task 9: final directory listing captured.

## GitHub repository
- [ ] README explains the activity.
- [ ] Screenshots are genuine, readable, and contain no secrets.
- [ ] Evidence log is complete.
- [ ] Reflection questions answered.
- [ ] `git status` checked before commit.
- [ ] Changes pushed to the correct GitHub repository.
